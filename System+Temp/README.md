# System and Temperature

This project demonstrates how system messages and the `temperature` parameter
influence an LLM response using the Groq API.

## Setup

Create a `.env` file in this folder:

```env
GROQ_API_KEY=your_groq_api_key_here
```

Install the dependencies and run:

```powershell
uv run Sys.py
```

Never commit the `.env` file or your API key.
